# Go Knicks!

## Description

In 1971, a man famous for casting theatrical "whammies" on opposing teams followed his favorite player to New York, eventually getting his hexes banned by the Knicks' front office.

Find the full birth name of the man who cast these 'whammies' (First, Middle, Last).

The Knicks played in the very first BAA (now NBA) game in 1946. What was the exact height (in feet and inches, format: X'Y") that guaranteed a fan free admission to that specific inaugural game?

The team's "Knickerbocker" moniker originates from a pseudonym used by Washington Irving for his 1809 book. What is the first name of this fictional author?

In 1947, the Knicks drafted the league's very first non-white player. What university did he attend?

Example Format: boroCTF{John_Jacob_Jingleheimer_6'9"_Rip_Rutgers}

## Solution Walkthrough

The first answer is Edward Marvin Cooper. After looking it up, you can find it is [Dancing Harry](https://en.wikipedia.org/wiki/Dancing_Harry), and [his name is Edward Marvin Cooper](https://www.alamy.com/edward-marvin-cooper-77-a-new-york-knicks-and-baltimore-bullets-super-fan-known-as-dancing-harry-gives-a-thumbs-up-after-receiving-his-second-vaccine-shot-for-covid-19-at-monteverde-a-senior-living-complex-in-park-circle-amy-davisbaltimore-suntnssipa-usa-image412456137.html).

The second answer is 6'8", which can be seen in [this post](https://www.instagram.com/p/DVu3EGfDXrS/).

The third answer is Diedrich. By searching `knickerbocker washington irving`, you can see the [Wikipedia page](https://en.wikipedia.org/wiki/A_History_of_New_York), and the answer is inside.

The last answer is Utah, which refers to the University of Utah. By searching `knicks first non-white player`, you can see [Wataru Misaka](https://zh.wikipedia.org/zh-tw/%E4%B8%89%E9%98%AA%E4%BA%99), and the answer is inside.
