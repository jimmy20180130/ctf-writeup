# Fireman

## 題目描述

Here's a real easy OSINT to give you guys a small break.

Find the name of the man in this image. FULL name including middle initial.

Then wrap it with boroCTF{} yourself. (Replace spaces with an underscore) Example flag: boroCTF{forever_f_flames}

## 解題思路

以圖搜圖以後可以看到[一篇貼文](https://www.facebook.com/groups/410267209587130/posts/1847388779208292/)

點進去[發文者](https://www.facebook.com/groups/410267209587130/user/574197891/)即可得到 flag

## Flag

```text
boroCTF{peter_c_lukens}
```
