# Intruder

## Description

I was talking with my friend Jman and he was telling me about his 21 year old discovery.

It was very crazy and he told me I was a skeptic, just like justinLife and other people.

Who found this discovery? Format: boroCTF{username}

## Solution Walkthrough

There are a few keywords in the challenge:

```text
Jman
21 year old discovery
justinLife
```

Start by searching for the clues that look like usernames, Jman and justinLife. You can find a 2005 Half-Life forum thread related to Project SKYBOX / Interloper.

The poster of that thread is `|DeV1RTU0S0|x`, which is the flag.

## Flag

```text
boroCTF{|DeV1RTU0S0|x}
```
