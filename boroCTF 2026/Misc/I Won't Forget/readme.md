# I Won't Forget

## Description

It seems the Republic tried to silence them, but nothing stays hidden forever.

What is the full name of the author?

Flag format: boroCTF{first_last}

## Solution Walkthrough

Scrolling to the bottom using a hex editor reveals that a zip file is hidden inside this PDF.

After extracting it, you can determine from REDACTED.txt that the author is Vladilena Milizé from 86-Eighty-Six.

## Flag

```text
boroCTF{vladilena_milizé}
```
