# Babel's Vault

## Description

My friend sent me a random codebase with a Library of Babel implementation. Apparently the author is well known to hide secrets in his code, but I don't see any here.

## Solution Walkthrough

1. **Step 1**:

    First, look at the provided `babel.py`:

    `page_from_seed()` adds a large offset to the seed and then converts it into a base55 string.

    ```python
    def page_from_seed(seed: int):
        seed += OFFSET
        chars = []
        for _ in range(940):
            seed, remainder = divmod(seed, 55)
            chars.append(ALPHABET[remainder])
        return "".join(chars)
    ```

    `image_from_seed()` subtracts another large offset from the seed and then converts it into a 15x15 RGB image.

    ```python
    def image_from_seed(seed: int):
        seed -= OFFSET_IMAGE
        pixels = []
        for _ in range(225):
            seed, r = divmod(seed, 256)
            seed, g = divmod(seed, 256)
            seed, b = divmod(seed, 256)
            pixels.append((r, g, b))
        return pixels
    ```

    Therefore, we can use these two functions to find the flag.

2. **Step 2**:

    In `page_from_seed()`, a 940-character page is generated, and the content of `AUTHORSNOTE.txt` happens to be exactly 940 characters long.

    This suggests that the author's note is not ordinary text, but a page generated by `page_from_seed()`.

    Thus, we can reverse the process:

    ```text
    作者筆記 -> base55整數 -> 原本的seed
    ```

    The conversion method of `page_from_seed()` is little-endian base55:

    ```python
    seed, remainder = divmod(seed, 55)
    chars.append(ALPHABET[remainder])
    ```

    So, when calculating in reverse, the i-th character represents the i-th digit:

    ```text
    ALPHABET.index(ch) * 55^i
    ```

    Python implementation:

    ```python
    def text_to_seed_value(s):
        n = 0
        mul = 1

        for ch in s:
            n += alphabet.index(ch) * mul
            mul *= 55

        return n
    ```

    Since `page_from_seed(seed)` adds an offset at the beginning, remember to subtract the offset after calculating the seed:

    ```python
    seed = text_to_seed_value(text) - offset
    ```

3. **Step 3**:

    After calculating the seed, pass it to `image_from_seed()` to convert the numbers into RGB pixels:

    ```python
    seed, r = divmod(seed, 256)
    seed, g = divmod(seed, 256)
    seed, b = divmod(seed, 256)
    pixels.append((r, g, b))
    ```

    Among the obtained pixels, many are `(0, 0, 0)`, while the valid pixels look like this:

    ```text
    (0, 0, 7)
    (0, 1, 6)
    (0, 3, 5)
    ...
    ```

    These RGB values do not look like real colors but rather like three-digit indices; for example, (0, 0, 7) represents the 7th position:

    ```text
    (0, 0, 7) -> 007
    (0, 1, 6) -> 016
    (0, 3, 5) -> 035
    ```

    Therefore, each non-zero pixel can be converted into a position:

    ```python
    pos = 100 * r + 10 * g + b
    ```

    Then, use these positions to read the characters from `AUTHORSNOTE.txt`.

4. **Step 4**:

    With these index values, you can write a script to retrieve the corresponding characters for each index:

    ```python
    positions = []

    for r, g, b in pixels:
        if (r, g, b) != (0, 0, 0):
            pos = 100 * r + 10 * g + b
            positions.append(pos)

    hidden = "".join(text[pos] for pos in positions)
    ```

    After running the script, you get:

    ```text
    boroCTFoneSeedCipherInInfinity
    ```

    Add the {} to get the flag.
