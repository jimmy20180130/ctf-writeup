# Disco

## Description

The hexagonal colors are simply beautiful.

## Solution Walkthrough

The challenge provides an image. By converting the 12 color blocks into RGB hex values and then converting each byte into ASCII, the flag can be obtained.

Some of the trailing `#000000` color blocks can be ignored, as they do not affect the flag.

## Flag

```text
boroCTF{nEv3r_l0$e_YoU4_Be@t}
```
