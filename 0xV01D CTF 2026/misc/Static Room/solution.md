# Static Room

## Description

The provided artifact contains everything needed to recover one valid flag.

Flag format : 0xV01D{......}

Submit the complete flag exactly as shown by the format, including the prefix 0xV01D and the braces.

## Solution Walkthrough

Listening to the audio file, you can tell it's Morse code.
Upload the audio file to https://morsecode.world/international/decoder/audio-decoder-adaptive.html to get the flag.

## Flag

```text
0xV01D{MORSE_MAKES_NOISE}
```
