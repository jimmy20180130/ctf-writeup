# Action Packed

## 題目描述 (Description)

An internal dashboard exposes convenience actions for trusted workflows. The interesting part is not the button, but the context around the request.

## 解題思路 (Solution Walkthrough)

Viewing the webpage source code did not reveal the flag, so I randomly entered values for Full Name and Department.  
After clicking the "Generate Master Token" button, the flag was obtained.
