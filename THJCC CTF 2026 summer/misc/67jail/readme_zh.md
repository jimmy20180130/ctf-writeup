# 67jail

## 題目描述

67676767

`nc chal.thjcc.org 9000`

## 解題思路

看 `jail.py` 可以發現輸入的長度必須剛好等於 6767，此外不能有底下幾個字元

```text
'"_`\#
```

此外 ascii 的英文字母和數字也會被封，還有就是分號只能一個，而且 `__builtins__` 被換掉，只剩 `print` / `open` / `chr` 可以用

接下來他是逐字檢查 NFKC 完的結果是否等於字元本身，以及該字元是否為合法的識別字，如果同時符合的話也會被拒絕

剛好全形的英文字母可以繞過這個，因為單一個全形字元 NFKC 完會變成半角，所以過得了檢查，但整個 NAME token 進到 lexer 之後會被正規化 (PEP 3131)，`ｐｒｉｎｔ` 讀進去就是 `print`

數字的話就要另外想辦法，在 python 裡面 true 就是 1，所以可以用 `(()==())` 代表 1，然後 `(()==()) + (()==())` 就是 2，以此類推，所以就可以組出任何的 ascii 碼 (要用的原因是因為雙引號和單引號被禁用，只能用 chr 來拼)

這裡把 1/2/4/8/16/32/64 先各存成一個變數 (`ａ` 到 `ｇ`)，之後任何 ascii 碼都可以用這七個加出來。不過分號只能一個而 `input()` 只讀一行，所以這些賦值不能一行一句，要用海象運算子串成一個 tuple 擠在同一個表達式裡，唯一的分號留給後面真正的 statement

所以最後的 payload 可以這樣寫 (`print(open('/flag').read())`)，並在最後一段之後加上一堆空格，讓長度可以為 6767

```text
(ａ:=(()==()),ｂ:=ａ+ａ,ｃ:=ｂ+ｂ,ｄ:=ｃ+ｃ,ｅ:=ｄ+ｄ,ｆ:=ｅ+ｅ,ｇ:=ｆ+ｆ);ｐｒｉｎｔ(ｏｐｅｎ(ｃｈｒ(ｆ+ｄ+ｃ+ｂ+ａ)+ｃｈｒ(ｇ+ｆ+ｃ+ｂ)+ｃｈｒ(ｇ+ｆ+ｄ+ｃ)+ｃｈｒ(ｇ+ｆ+ａ)+ｃｈｒ(ｇ+ｆ+ｃ+ｂ+ａ)).ｒｅａｄ())
```
